# Using Real MCPhases Data

## Current State: Synthetic Training
Currently, the training pipeline uses **synthetic patient data** generated by `PatientSimulator`. This allows you to:
- Train and test the model without external dependencies
- Run `python -m app.training.train` immediately
- Verify the entire pipeline works

**No MCPhases dataset required to get started.**

## When You Have MCPhases Data

### 1. Download from PhysioNet

```bash
# Visit https://physionet.org/content/mcphases/1.0.0/
# Download and extract to: ./data/mcphases/
```

Expected structure:
```
data/mcphases/
├── mcphases-notes.txt
├── RECORDS
├── RECORDS-annotated
├── p001/
│   ├── p001_0d_01.txt
│   ├── p001_0d_02.txt
```

```env
MCPHASES_PATH=./data/mcphases
```

Or with absolute path:
```env
MCPHASES_PATH=/Users/your-name/Downloads/mcphases-1.0.0
```

Or on Windows:
```env
MCPHASES_PATH=C:\Data\mcphases
```

## Why Synthetic Now, Real Later?

| Aspect | Synthetic | Real MCPhases |
|--------|-----------|---------------|
| **Availability** | Immediate | Requires download |
| **Coverage** | All 3 classes balanced | Imbalanced (menstrual cycle focus) |
| **Vital Signs** | Complete | Sparse (HR, temp only) |
| **Training Speed** | Fast | Slower (more data preprocessing) |
| **Clinical Relevance** | Good for demo | Better for real deployment |

## Path Resolution Rules

The config uses this priority:

1. **Environment variable** → `MCPHASES_PATH` from `.env`
2. **Fallback** → `./data/mcphases` (relative to backend dir)

To override, set in `.env`:
```env
MCPHASES_PATH=/absolute/path/to/mcphases
```

Or set system variable:
```bash
export MCPHASES_PATH=/path/to/mcphases
python -m app.training.train
```

## Data Format Compatibility

MCPhases provides:
- Daily LH (luteinizing hormone)
- E3G/PdG metabolites
- Wearable vitals (HR, skin temp, RR)
- Sleep metrics
- Mood/symptom logs

Our model expects:
- BP (systolic/diastolic)
- Heart rate ✓ (available in MCPhases)
- Temperature ✓ (skin temp from wearable)
- Respiratory rate ✓ (available)
- Blood glucose (NOT in MCPhases)
- Blood pH, Bicarbonate (NOT in MCPhases)
- Urine/Capillary tests (NOT in MCPhases)

**Challenge:** MCPhases lacks typical blood/lab values. Solutions:
1. **Augment** synthetic data with MCPhases vitals
2. **Synthesize** missing values from patterns
3. **Use subset** of features that MCPhases provides
4. **Combine** with another clinical dataset
